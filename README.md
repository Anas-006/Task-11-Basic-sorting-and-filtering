Task 11 – Basic Data Sorting & Filtering

Project Overview

This project focuses on basic data exploration using sorting and filtering techniques in Microsoft Excel. The Superstore dataset was used to answer simple business questions related to sales, regions, categories, discounts, and profit.

Objective

- Practice basic data sorting and filtering.
- Explore sales data using Excel filters.
- Answer simple business questions from the dataset.
- Keep the original raw data unchanged.

Dataset

Dataset: Superstore Sales Dataset

The analysis used relevant columns such as:

- Product Name
- Sales
- Region
- Category
- Discount
- Profit
- Order ID

Tools Used

- Microsoft Excel

Approach

The raw data was preserved without modification. A separate worksheet was used for the Task 11 analysis.

Excel sorting and filtering features were used to explore the data and identify relevant records. The "SUBTOTAL" function was used to calculate totals for filtered data where required.

Business Questions

1. Which product has the highest sales?
2. Which region has the highest sales?
3. Which category has the highest sales?
4. Which orders have a discount greater than 50%?
5. Which orders have negative profit?

Key Outcomes

- Identified the product with the highest sales.
- Compared sales across different regions.
- Compared sales across product categories.
- Identified records with discounts greater than 50%.
- Identified orders with negative profit.

Conclusion

The task provided practical experience in using Excel sorting, filtering, and basic functions for data exploration. It demonstrated how simple Excel techniques can be used to answer common business questions while preserving the original dataset.
